# 🥋 NotebookLM - Nutrição Esportiva para Esportes de Combate
Este projeto foi desenvolvido como parte do desafio da DIO com o objetivo de explorar o NotebookLM como ferramenta de aprendizagem ativa.

O caderno temático foi criado para reunir informações científicas sobre nutrição aplicada aos esportes de combate e modalidades de alta intensidade, utilizando artigos científicos e diretrizes reconhecidas internacionalmente como base de conhecimento.
